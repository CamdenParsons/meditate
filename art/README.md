# art

ASCII art shown above the clock during a session.

- `figure.txt` — the seated Buddha, shown on its own when the terminal is
  too small for the halo.
- `buddha.txt` — the same figure with a radiating halo. Generated by
  `../scripts/make_rays.py`; edit `figure.txt` and re-run that rather
  than editing this file by hand.

## Credit

The Buddha is by **hjw** (Hayley Jane Wakenshaw), from
https://asciiart.website/art/3832.

The drawing has been modified: the ground line it sat on and the `hjw`
signature in its lower right were removed, so the figure floats inside
the halo. The signature was the artist's mark, so the credit lives here
and in the project README instead. This is a personal tool and the art is
not redistributed as anyone else's work.

## Using your own

Point `MEDITATE_ART` at any `.txt` file:

```
MEDITATE_ART=art/figure.txt ./meditate 20
```

Lines are centred as a block, so art keeps its own internal alignment.
